# Kumbukumbu ya Mzee Exaudy Mdegellah

Tovuti ya kumbukumbu na heshima kwa Mzee Exaudy Mdegellah (Septemba 1967 — 22 Septemba 2026).

Imeandaliwa kama kumbukumbu ya familia, maombolezo na shukrani.

## Deployment
GitHub Actions deploys the site to the configured hosting destination. The repository is currently being repurposed from the previous Ethernet project to this memorial website.

## Content
- Historia fupi ya maisha
- Watoto wanne: wasichana 3 na mvulana 1
- Ujumbe wa heshima na shukrani
- Kumbukumbu ya mazishi ya 23 Septemba 2026
